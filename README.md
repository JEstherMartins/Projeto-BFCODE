# 💜 BF Code — Tecnologia para Todas!

### Educação tecnológica, inclusão e oportunidades para todas as pessoas.

---

## 📌 Sobre o Projeto

O **BF Code** é um projeto académico desenvolvido como parte da disciplina de **Desenvolvimento de Software I**, do curso de Licenciatura em Computação da Universidade Federal do Recôncavo da Bahia (UFRB).

A plataforma tem como objetivo promover o acesso à educação tecnológica de forma inclusiva e acessível, incentivando principalmente a participação de mulheres cis, mulheres trans, pessoas negras e pessoas com deficiência no universo da tecnologia.

Acreditamos que o conhecimento tecnológico deve ser uma oportunidade para todas as pessoas, contribuindo para a diversidade, a equidade e a inclusão no mercado de trabalho.

## 🎯 Objetivos

- Democratizar o acesso ao conhecimento tecnológico.
- Incentivar mulheres a ingressarem no universo da programação.
- Promover a inclusão de pessoas negras, trans e com deficiência.
- Disponibilizar conteúdos educativos sobre programação e tecnologias digitais.
- Contribuir para a redução das desigualdades no mercado tecnológico.

## 💻 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando:

- **HTML5:** estruturação das páginas do site.

## 📚 Funcionalidades

O site conta com as seguintes páginas:

- **Página Inicial:** apresentação da plataforma e dos seus objetivos.
- **Sobre Nós:** história, missão, visão e valores da BF Code.
- **Cursos:** apresentação de conteúdos e materiais educativos sobre programação e tecnologia.
- **Contato:** formulário para envio de dúvidas, sugestões e mensagens.
